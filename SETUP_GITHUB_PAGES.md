# GitHub Pages Setup Instructions

The site has been pushed to GitHub. Now you need to enable GitHub Pages:

## Steps:

1. Go to: https://github.com/RandyVentures/Rally-Track-Site/settings/pages

2. Under "Source", select:
   - **Source:** GitHub Actions

3. Save (it should auto-detect the workflow)

4. Wait 2-3 minutes for the first deployment to complete

5. Your site will be live at:
   **https://randyventures.github.io/Rally-Track-Site/**

## URLs for App Store Connect:

Once GitHub Pages is enabled, use these URLs:

- **Privacy Policy:** `https://randyventures.github.io/Rally-Track-Site/privacy.html`
- **Support:** `https://randyventures.github.io/Rally-Track-Site/support.html`  
- **Marketing URL:** `https://randyventures.github.io/Rally-Track-Site/`

## Verify It's Working:

1. Go to: https://github.com/RandyVentures/Rally-Track-Site/actions

2. You should see a "Deploy GitHub Pages" workflow running or completed

3. Once it's green (✓), visit the live site

## Troubleshooting:

If the workflow fails:
- Check the Actions tab for error details
- Make sure GitHub Pages is enabled in Settings → Pages
- Make sure the source is set to "GitHub Actions"
