# RallyTrack Website

Official website for RallyTrack - the simplest pickleball score tracking app for iOS.

## 🌐 Live Site

**Production:** https://randyventures.github.io/Rally-Track-Site/

## 📄 Pages

- **Home:** `site/index.html` - Main landing page
- **Privacy:** `site/privacy.html` - Privacy policy (required for App Store)
- **Support:** `site/support.html` - Support & FAQ page

## 🚀 Deployment

The site is automatically deployed to GitHub Pages via GitHub Actions when changes are pushed to the `master` branch.

Workflow file: `.github/workflows/pages.yml`

## 🛠️ Local Development

To view locally, just open `site/index.html` in a browser. No build step required!

## 📝 URLs for App Store Connect

Use these URLs when submitting to App Store Connect:

- **Privacy Policy URL:** `https://randyventures.github.io/Rally-Track-Site/privacy.html`
- **Support URL:** `https://randyventures.github.io/Rally-Track-Site/support.html`
- **Marketing URL:** `https://randyventures.github.io/Rally-Track-Site/`

## 🎨 Design

- Clean, modern design matching iOS aesthetics
- Green primary color (#00D563) for RallyTrack branding
- Responsive layout (mobile-first)
- Based on the Fillin site structure
